# Veridian IT Service Agent

🚀 **Live Demo:** https://veridian-it-service-agent-jdjtqgxglmdquq8svosr47.streamlit.app/

📂 **GitHub Repository:** https://github.com/23csu404/Veridian-IT-Service-Agent

A full-stack prototype for **AIONOS Agentic AI Factory — Assignment 2: Internal Service Agent**.

## Features

- Natural-language IT issue understanding
- Intent detection
- Entity extraction
- TF-IDF policy retrieval
- Cosine similarity for policy matching
- Policy-controlled decision engine
- Resolve / Clarify / Escalate outcomes
- Structured ticket creation
- SQLite persistence
- Audit trail
- Source policy display
- Employee requests viewer
- Ticket queue viewer
- Knowledge base viewer
- FastAPI backend + Streamlit frontend
